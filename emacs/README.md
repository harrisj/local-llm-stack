# Emacs

I use Doom Emacs as my IDE/editor and I have added some logic (created with the aid of Google Gemini) to launch a pi window as a side window. Originally I was using the [pilish](https://github.com/dnouri/pilish) extension to call Pi, but I had some mixed success with the interface, since it doesn't support TUI natively. I may go back to using it, but for now I am using a ghostty terminal instead. This directory contains a copied excerpt of my config
